Desarrollar un programa en el lenguaje que prefieran, sobre un tema de elección libre, en el que se modelen entidades relacionadas entre sí utilizando programación orientada a objetos.
 El sistema debe incluir al menos 4 clases principales y debe evidenciar relaciones entre ellas. 
Por ejemplo, una entidad puede contener a otra, depender de otra o vincularse con varias. 
El programa debe permitir crear objetos, relacionarlos y mostrar su funcionamiento con datos de ejemplo. 
Se deberá aplicar encapsulamiento, constructores, atributos, métodos y una organización clara del código. 
Además, deberán entregar una breve explicación indicando cuál es el tema elegido, qué representa cada clase y qué tipo de relación existe entre ellas. 
Como mínimo, el programa debe mostrar por consola una prueba de uso donde se vea claramente cómo interactúan las entidades. 
Extras opcionales: agregar validaciones, menús, búsqueda de datos o persistencia simple en archivo. 
Objetivo: comprender cómo se representan y utilizan las relaciones entre clases dentro de un sistema real o simulado.
